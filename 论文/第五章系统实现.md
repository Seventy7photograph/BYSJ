### 5.1.4 系统部署结构图

系统采用前后端分离的部署架构，具体结构如下：

1. **前端层**：部署在Web服务器（如Nginx）上，负责用户界面展示和交互
2. **后端层**：部署在应用服务器上，处理业务逻辑和数据处理
3. **数据库层**：独立部署的MySQL数据库，存储系统数据
4. **缓存层**：Redis缓存，提升系统性能

这种架构具有良好的扩展性和维护性，各层之间通过API接口进行通信，实现了前后端的解耦。

## 5.2 系统功能模块实现

### 5.2.1 用户认证模块

用户认证模块负责用户的注册、登录、密码重置和权限管理。

**功能描述**：

- 用户注册：新用户通过填写基本信息完成注册
- 用户登录：用户通过账号密码登录系统
- 密码重置：用户忘记密码时通过邮箱或手机验证重置
- 权限管理：基于角色的权限控制，区分普通用户、商家和管理员

**界面描述**：

登录界面包含账号和密码输入框，以及登录、注册和忘记密码按钮。界面设计简洁明了，使用Element Plus组件库实现，支持表单验证功能。登录成功后，系统会将用户信息和 token 存储到本地存储，并跳转至首页。

**核心代码**：

```vue
<template>
  <div class="login-container">
    <h2>用户登录</h2>
    <el-form :model="loginForm" :rules="rules" ref="loginFormRef" label-width="80px">
      <el-form-item label="账号" prop="username">
        <el-input v-model="loginForm.username" placeholder="请输入账号"></el-input>
      </el-form-item>
      <el-form-item label="密码" prop="password">
        <el-input type="password" v-model="loginForm.password" placeholder="请输入密码"></el-input>
      </el-form-item>
      <el-form-item>
        <el-button type="primary" @click="handleLogin">登录</el-button>
        <el-button @click="goToRegister">注册</el-button>
        <el-button @click="goToResetPassword">忘记密码</el-button>
      </el-form-item>
    </el-form>
  </div>
</template>

<script lang="ts" setup name="Login">
import { ref, reactive } from 'vue'
import { useRouter } from 'vue-router'
import { login } from '@/api/user/auth'

const router = useRouter()
const loginFormRef = ref()

const loginForm = reactive({
  username: '',
  password: ''
})

const rules = {
  username: [{ required: true, message: '请输入账号', trigger: 'blur' }],
  password: [{ required: true, message: '请输入密码', trigger: 'blur' }]
}

const handleLogin = async () => {
  if (loginFormRef.value) {
    await loginFormRef.value.validate(async (valid) => {
      if (valid) {
        try {
          const res = await login(loginForm)
          localStorage.setItem('token', res.data.token)
          localStorage.setItem('userInfo', JSON.stringify(res.data.user))
          router.push('/')
        } catch (error) {
          console.error('登录失败', error)
        }
      }
    })
  }
}

const goToRegister = () => {
  router.push('/register')
}

const goToResetPassword = () => {
  router.push('/reset-password')
}
</script>
```

**代码解释**：

- 登录页面使用Element Plus的Form组件实现表单验证
- 通过API调用实现登录功能
- 登录成功后将token存储到本地存储
- 提供注册和忘记密码的跳转链接

```java
@RestController
@RequestMapping("/api/merchant/inventory")
public class InventoryController {
    @Autowired
    private InventoryService inventoryService;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @GetMapping("/list")
    public Result<List<Inventory>> getInventoryList(@RequestParam(required = false) String keyword) {
        // 尝试从Redis缓存获取
        String cacheKey = "inventory:list:" + (keyword != null ? keyword : "all");
        List<Inventory> inventoryList = (List<Inventory>) redisTemplate.opsForValue().get(cacheKey);
        
        if (inventoryList == null) {
            // 缓存未命中，从数据库查询
            inventoryList = inventoryService.getInventoryList(keyword);
            // 缓存结果，设置过期时间为5分钟
            redisTemplate.opsForValue().set(cacheKey, inventoryList, 5, TimeUnit.MINUTES);
        }
        
        return Result.success(inventoryList);
    }
    
    @PutMapping("/update")
    public Result<?> updateInventory(@RequestBody InventoryUpdateDTO dto) {
        inventoryService.updateInventory(dto);
        // 清除缓存
        redisTemplate.delete("inventory:list:*");
        return Result.success();
    }
    
    @GetMapping("/history")
    public Result<List<InventoryHistory>> getInventoryHistory(@RequestParam Long inventoryId) {
        return Result.success(inventoryService.getInventoryHistory(inventoryId));
    }
}
```

**后端代码解释**：
- 使用Redis缓存提升库存查询性能
- 实现库存更新和历史记录查询功能
- 当库存更新时清除相关缓存
- 提供库存历史记录查询接口

```vue
          <el-button type="danger" @click="removeFromCart(item.id)">删除</el-button>
        </div>
      </div>
    </div>

  await deleteCartItem(id)

}

  // 结算逻辑
}
```

### 5.2.7 数据统计模块

数据统计模块用于统计和分析系统的各种数据，包括店铺、订单、商品和用户数据。

**功能描述**：

- 店铺数据统计：统计店铺的销售额、订单量、客流量等数据
- 订单数据统计：统计订单的数量、金额、状态分布等数据
- 商品数据统计：统计商品的销量、库存、受欢迎程度等数据
- 用户数据统计：统计用户的注册量、活跃度、消费情况等数据

**界面描述**：

数据统计界面包含多个统计图表，如折线图、柱状图和饼图等。界面顶部有时间选择器，用户可以选择不同的时间范围进行数据查询。界面使用ECharts库实现数据可视化，展示各类数据的统计结果和趋势分析。

**核心代码**：

```vue
<template>
```
